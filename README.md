# NYC_Taxi_Trips_pipeline
ETL Pipeline for NYC Taxi (dataset)[https://www.kaggle.com/datasets/elemento/nyc-yellow-taxi-trip-data?select=yellow_tripdata_2015-01.csv]. Built with PySpark and Delta Lake.
Featuring a modular architecture and dual-environment deployment (Local Docker & Databricks Jobs). Includes data quality filtering andfeature engineering
